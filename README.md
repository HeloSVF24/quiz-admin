# 🎯 QuizCorp Admin — Painel Administrativo de Perguntas e Respostas

> **Atividade Avaliativa:** Desenvolvimento de um CRUD completo (Criar, Ler, Atualizar e Deletar) para um painel administrativo de gestão de quiz, perguntas e alternativas.

---

## 💻 Sobre o Projeto

O **QuizCorp Admin** é uma aplicação web desenvolvida com **identidade visual corporativa**, focada na gestão e cadastro de perguntas e respostas para plataformas de quiz. A interface é totalmente responsiva e amigável, permitindo que administradores realizem o cadastro de perguntas, definam as alternativas e marquem a resposta correta.

---

## 🚀 Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3, Bootstrap Icons
- **Back-end:** PHP 8+
- **Banco de Dados:** MySQL / MariaDB
- **Ambiente de Desenvolvimento Local:** XAMPP, Visual Studio Code

---

## 📌 Funcionalidades do Sistema (CRUD)

- [x] **Criar (Create):** Formulário completo para cadastro de perguntas com 4 alternativas e seleção obrigatória da resposta correta.
- [x] **Ler (Read):** Tabela de exibição de perguntas cadastradas dinamizada via banco de dados MySQL, indicando a resposta correta em destaque.
- [x] **Deletar (Delete):** Ação de exclusão individual de perguntas cadastradas com modal/alerta de confirmação.
- [x] **Validação do Lado do Cliente:** Validação de formulário via JavaScript e classes nativas do Bootstrap, impedindo envios com campos em branco.
